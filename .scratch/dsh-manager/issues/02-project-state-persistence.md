# 02: 项目落地与状态回读

**What to build:** 在主对话里启动一个项目，给出目标与验收标准后，这些内容以 markdown 落在 `.scratch/` 下，人能直接读懂。用 `/manager status` 能把它们读回来。关掉会话重新打开，状态还在，不需要重新输入。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 启动项目后生成项目状态与验收标准两份 markdown，内容人可读
- [ ] `/manager status` 输出当前项目的目标与验收标准
- [ ] 关闭会话再新开会话，状态仍可读回
- [ ] 状态文件被手工改坏时，`status` 报出可理解的问题而不是崩溃
- [ ] 核心逻辑有测试覆盖：从单一接口驱动、外部能力全部用注入的假件，不依赖真实文件系统竞争
