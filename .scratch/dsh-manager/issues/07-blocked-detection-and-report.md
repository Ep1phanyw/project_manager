# 07: 阻塞判定与报告

**What to build:** 只有三种情形能进入阻塞：同一部分连续两次验收失败且失败原因未变、缺少只有用户能提供的东西、需要改动验收标准本身。阻塞时产出一份报告，说明卡在哪、试过什么、需要用户提供什么；模型宣称阻塞一律无效。

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 同一部分连续两次验收失败且原因未变时自动进入阻塞
- [ ] 缺少只有用户能提供的东西时可进入阻塞，并说明缺什么
- [ ] 需要改动验收标准时可进入阻塞，并说明为什么现有标准做不到
- [ ] 除上述三种情形外，模型宣称阻塞被拒
- [ ] 阻塞时产出报告：卡在哪、试过什么、需要用户提供什么
- [ ] 模型无法自行降低验收标准，只能提出建议并等待用户裁决
