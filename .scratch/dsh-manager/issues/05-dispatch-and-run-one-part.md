# 05: 跑通一个部分

**What to build:** 批准后取到第一个可派分的部分，起一个独立上下文的子对话，把该部分的任务交给它；子对话结束后交回结构化回报，回报被记录到该部分的状态里，完整记录落盘备查。回报结构不合规会被拒绝。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 批准后能取到第一个可派分的部分
- [ ] 派分后真的起一个独立上下文的子对话，并收到该部分的任务描述
- [ ] 子对话结束后，其结构化回报被记录进该部分的状态
- [ ] 子对话的完整记录落盘，可事后查看
- [ ] 回报结构不合规（缺状态、缺证据、状态值非法）时被拒并说明原因
- [ ] 子对话自身失败（报错、中止）不会让整个项目崩掉，而是记为可重试
