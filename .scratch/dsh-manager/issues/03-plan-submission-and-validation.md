# 03: 计划提交与校验

**What to build:** 提交一份含多个部分的计划，每个部分声明依赖、涉及的文件集和证据类型。插件校验它：依赖指向不存在的部分、依赖成环、文件集重叠却没有依赖边、证据类型非法，都被拒绝并指出具体原因；合法的计划被接受并落盘。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 提交合法计划后计划落盘，并在 `status` 中可见
- [ ] 依赖指向不存在的部分时被拒，并指出是哪一条
- [ ] 依赖成环时被拒，并指出环上的部分
- [ ] 两个部分文件集重叠却没有依赖边时被拒，并指出是哪两个部分
- [ ] 证据类型不在允许集合内时被拒
- [ ] 上述每种拒绝情形都有测试覆盖
