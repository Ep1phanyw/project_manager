# 09: 进度总览与断点续跑

**What to build:** `/manager status` 显示项目当前所处阶段、每个部分的状态与重试次数。关闭会话再打开能从上次的位置继续，不必重新批准计划；阻塞中的项目重开后仍显示同一个阻塞原因。

**Blocked by:** 07、08

**Status:** ready-for-agent

- [ ] `/manager status` 显示项目当前阶段（规划 / 待批准 / 执行 / 待确认 / 阻塞 / 完成）
- [ ] `status` 显示每个部分的状态与重试次数
- [ ] 关闭会话后重新打开，能从上次位置继续，不需要重新批准计划
- [ ] 阻塞状态的项目重开后仍显示同一个阻塞原因
- [ ] 已完成的项目重开后显示为完成，且不再派分任何部分
