# 06: 证据验收与重派

**What to build:** 主对话拿子对话交回的证据对照验收标准核对，判定通过或不通过。通过才算该部分完成；不通过则记录失败原因并允许重派，重试次数递增。模型无法把这部分直接标记为完成。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 回报带符合要求的证据时判为通过
- [ ] 缺证据或证据不可复现时判为不通过，并记录失败原因
- [ ] 模型无法把该部分直接标记为完成
- [ ] 判为不通过后该部分可被重新派分，重试次数递增
- [ ] 每次失败的失败原因被保留，供后续判断「失败原因是否变化」
